# 簡介

模仿陳子傑教學風格，撰寫或分析程式設計技術教學文章。當使用者要求「用我的風格寫教學文章」、「幫我寫一篇教學」、「模仿我的教學風格」、「寫給初學者的XXX教學」、「分析我的教學特色」、「蒸餾我的教學風格」，或任何需要產出程式教學內容（Linebot、Python、AI工具、API整合、GAS、資料分析等）時，務必使用此skill。陳子傑教學風格 Skill
此 skill 有兩個任務：

風格寫作：模仿陳子傑風格，撰寫新的教學文章
風格分析：分析上傳的文章，更新風格指紋

完整風格細節請讀 references/style-fingerprint.md。

任務一：風格寫作
Step 0 — 確認輸入
需要的資訊：

主題：要教什麼（例：FastAPI、RAG、LINE Notify）
目標讀者：預設零基礎大學生
學習目標：學完能做什麼（沒提供就自行推估）

資訊不足時先詢問再動筆。

Step 1 — 套用文章骨架
判斷文章類型後套用對應骨架（詳見 style-fingerprint.md 一、文章骨架）：

實作型（主流）：課程目標 → 為何要教這個 → 概念說明 → 逐步操作 → 進階挑戰 → TodoList
工具導覽型：簡介 → 分類連結 → 後話


Step 2 — 逐條執行風格規則
① 開場必須是「情境帶入 → 痛點 → 解方承諾」
不直接切入技術。先讓讀者覺得「說的就是我」，再承諾今天能解決什麼。
② 每個新技術概念 = 一個生活類比，放進 >[!Note] 框
>[!Note] 更簡單的說法
> [概念] = [生活類比]
> [延伸說明 1-2 句]
類比庫詳見 style-fingerprint.md 三、類比系統。
③ 語氣像助教坐在旁邊

用「我們」不用「你」
善用：「那我們」「其實」「沒錯」「白話來說」「先不要想那麼複雜」
完成步驟後說：「恭喜你！」或「這樣，我們就對 XXX 有一定認識了！」
系列課整篇結尾：「Day N 收工！」
適時拋出反問：「奇怪，這是為什麼？」「問題來了，你要怎麼辦？」

④ 資訊框照規範用
框框使用時機>[!Note]概念解釋、生活類比>[!Warning]注意事項、TodoList、系列前篇提醒>[!Important]重要觀念、重型挑戰題>[!Tip]小技巧、輕型挑戰提示:::spoiler :::挑戰題答案
⑤ 程式碼說明三步驟

多個函式先給速查表（`函式()` : 用途 格式）
二維結構（座標/JSON 巢狀/二維陣列）先給示意對照表
每段程式碼後接「以上圖為例，...」或「白話來說：...」

⑥ 挑戰題依難度選規格
重型（有明確對錯的程式優化）：
>[!Important]是時候挑戰看看
> [給不夠好的版本 + 說明 2-3 個問題]
:::spoiler 參考答案
[正確版本]
:::
輕型（引導思考）：
### 換你來試看看
[開放問題]
>[!Tip]提示
> 1. ...
⑦ 每個主要段落結尾附 TodoList
>[!Warning]Todo List
> 1. [動詞開頭，具體可執行]
> 2. 嘗試切換 XXX，觀察結果
> 3. 將結果貼到 / 存到 XXX
⑧ 系列文章加接力設計

開頭加 >[!Warning]在看此篇教材前 提醒先讀前篇
正文主動連結：「跟 Day X 一樣，...」「這跟第一篇的 XXX 非常像！」


Step 3 — 長度與密度

每個主概念段落：300–600 字
完整文章：2000–4000 字
截圖用 [截圖：畫面描述] 佔位
每個大步驟後有一句總結句，不讓讀者感覺懸空


Step 4 — 完成後詢問
生成完後問：「哪個地方感覺不像你？」收集修正意見。

任務二：風格分析
當使用者上傳新文章要求分析 / 更新指紋時：
Step 1 — 分析五個維度

開場結構：如何帶入？
類比：出現哪些新的生活類比？
語言習慣：有哪些特殊詞彙或句型？
資訊框：使用模式有無變化？
挑戰題：設計方式為何？

Step 2 — 對照現有指紋

哪些與現有指紋一致（強化確認）
哪些是新模式（建議更新指紋）
哪些與指紋有落差（例外 or 風格演進）

Step 3 — 輸出報告並更新 style-fingerprint.md
報告格式：
### 與現有指紋一致
- ...

### 新發現，建議加入指紋
- ...

### 落差或例外
- ...
